# Modelo: inventário do uso atual de agentes

Proposta do workshop. Preenchido antes do dia 1, por uma pessoa de cada time, sem nomear quem usa o quê. Ele mostra o que a semana pode aproveitar e o que a política de uso (modelo 21) precisa cobrir.

```markdown
Time: <nome do time>.

| Pergunta | Resposta |
|---|---|
| Quantas pessoas do time usam agentes hoje, e com que frequência? | |
| Em conta da empresa ou em conta pessoal? | |
| Que tipo de dado já foi enviado ao modelo? | |
| Que instruções ou prompts o time repete? Onde estão? | |
| Alguém escreve specs para o agente? Em que formato (por exemplo, OpenSpec)? | |
| A spec passa por revisão de outro modelo ou de outra pessoa? | |
| O teste é escrito e visto falhando antes do código? | |
| Quem pode ser a pessoa de referência do time nesta semana? | |
```

As specs e os prompts existentes são insumo do dia 1 (o `CLAUDE.md`) e do dia 3 (o formato da spec). O uso em conta pessoal é migrado antes do dia 1.
