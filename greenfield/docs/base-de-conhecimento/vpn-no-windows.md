# Configurar a VPN no Windows

1. Abra o Portal da Empresa e instale o cliente de VPN.
2. Abra o cliente e informe o endereço `vpn.empresa.example`.
3. Entre com o e-mail e a senha do portal e aprove o pedido no app de segundo fator.

Se a conexão cair a cada poucos minutos, desligue o Wi-Fi economizador de energia nas opções de rede.
