# Instalar software homologado

1. Abra a Central de Software (Mac) ou o Portal da Empresa (Windows).
2. Procure o programa pelo nome e clique em Instalar.

Programa que não está na lista precisa de avaliação da TI: abra um chamado com o nome do programa e o motivo.
