# Configurar a VPN no Mac

1. Abra o app Central de Software e instale o cliente de VPN.
2. Abra o cliente e informe o endereço `vpn.empresa.example`.
3. Entre com o e-mail e a senha do portal e aprove o pedido no app de segundo fator.

Se o macOS pedir permissão para adicionar a configuração de VPN, aceite em Ajustes do Sistema.
